# Shape an openFDA table: its columns in order, dates and logicals typed

Shape an openFDA table: its columns in order, dates and logicals typed

## Usage

``` r
shape_openfda_table(rows, spec, table)
```

## Arguments

- rows:

  data.frame (possibly with no rows or columns)

- spec:

  one
  [`openfda_table_specs()`](https://docs.ropensci.org/dbparser/reference/openfda_table_specs.md)
  entry

- table:

  table name, for errors

## Value

tibble
