# DPD tables as in Health Canada's read-me

File stem, columns in file order (read-me names, lower case), integer
and date columns. The read-me calls the biosimilar files `bios*.txt`;
the zips hold `biosimilar*.txt`. The therapeutic class files hold one
unnamed field after the three named ones, which must be empty.

## Usage

``` r
dpd_table_specs()
```

## Value

named list of table specs
