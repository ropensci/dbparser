# Parse openFDA dates (YYYYMMDD)

Parse openFDA dates (YYYYMMDD)

## Usage

``` r
parse_openfda_date(values, label)
```

## Arguments

- values:

  character vector; NA and "" give NA

- label:

  where the values come from, for the error

## Value

Date; stops when a set value is not a YYYYMMDD date
